# Simulação de tanque

`Tanque` representa um veículo com modelo e nível de combustível, desconta consumo e informa quando o nível cai abaixo de 20%. `TesteTanque` simula viagens com consumo aleatório e mostra os níveis finais.

Classes: `Tanque.java` e `TesteTanque.java`. Compile ambas e execute `TesteTanque`.
