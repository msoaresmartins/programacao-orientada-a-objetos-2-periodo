# Ninjas com atributos privados

`Ninja` usa atributos privados, getters, setters, construtores com diferentes parâmetros e um contador estático. `Programa` lê dados, cria objetos e simula treino e descanso em rodadas aleatórias.

Classes: `Ninja.java` e `Programa.java`. Compile ambas e execute `Programa`.
