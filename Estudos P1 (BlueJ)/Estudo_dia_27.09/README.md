# Estudo de construtores e encapsulamento

`Ninja` usa atributos privados, métodos de acesso, três construtores e um contador estático de objetos. `Programa` cria ninjas de formas diferentes e simula rodadas aleatórias de treino ou descanso.

Classes: `Ninja.java` e `Programa.java`. Compile ambas e execute `Programa`.
