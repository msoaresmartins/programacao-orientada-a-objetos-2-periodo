# Gerenciamento de baterias

`Bateria` oferece construtores, consumo, recarga, consulta de carga e alertas para carga baixa. `TesteBateria` cria três baterias, simula operações com consumo aleatório e mostra o estado final.

Classes: `Bateria.java` e `TesteBateria.java`. Compile ambas e execute `TesteBateria`.
