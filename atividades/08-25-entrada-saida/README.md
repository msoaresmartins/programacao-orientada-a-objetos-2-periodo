# Entrada e saída - 25/08

Cinco exercícios com entrada pelo teclado. Calculei circunferência, arredondamento, juros compostos, trabalho de uma força e distância entre dois pontos.

Cada arquivo, de `Ex1.java` até `Ex5.java`, tem seu próprio `main`. Para testar um deles, compile as classes e execute, por exemplo, `java Ex1`.
