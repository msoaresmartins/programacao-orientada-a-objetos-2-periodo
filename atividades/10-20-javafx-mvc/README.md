# Calculadora de Bhaskara com JavaFX e MVC

Projeto da disciplina de Programação Orientada a Objetos.

Calculadora de Bhaskara feita com JavaFX. A tela recebe `a`, `b` e `c` e mostra o delta e as raízes reais. Também tem um botão para limpar os campos e mensagens de erro para entradas inválidas.

Separei o cálculo na classe `EquacaoSegundoGrau`, a janela em `BhaskaraView` e `bhaskara.fxml`, e as ações dos botões em `BhaskaraController`.

O [relatório em PDF](relatorio.pdf) reúne as telas, os testes e os prints do código. Esta pasta contém o relatório, sem os arquivos `.java` e `.fxml` separados.
