# Entrada, processamento e saída

Cinco exercícios independentes que recebem dados pelo teclado: `Ex1` calcula a circunferência; `Ex2` arredonda um número; `Ex3` calcula o montante com juros compostos; `Ex4` calcula o trabalho de uma força; `Ex5` calcula a distância entre dois pontos.

Cada arquivo `Ex1.java` a `Ex5.java` possui seu próprio método `main`. Compile e execute o exercício desejado.
