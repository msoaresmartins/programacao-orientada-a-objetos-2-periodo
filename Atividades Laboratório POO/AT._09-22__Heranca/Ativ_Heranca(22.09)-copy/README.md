# Herança e polimorfismo

`Ninja` define as ações de apresentação e treino. `Hokage` herda de `Ninja`, redefine essas ações e acrescenta `governarVila`. `Main` cria os dois tipos e demonstra polimorfismo com uma referência `Ninja` apontando para um `Hokage`.

Classes: `Ninja.java`, `Hokage.java` e `Main.java`. Para executar, compile as três classes e inicie `Main`.
